noteDraft - 台本・プロット・執筆特化メモ帳

スワイプや矢印キーで「話者（ラベル）」を軽快に切り替えながら、思考を止めずに台本・プロット・小説の下書き・進行表などを組み立てられるブラウザベースの執筆特化メモ帳です。

🔗 アプリを使う（公開URL）

👉 https://saba-2326.github.io/noteDraft/
（※PC・スマホのブラウザからそのまま利用できます。ChromeやEdgeの「アプリとしてインストール」を使うと専用ウィンドウで起動できます）

✨ 主な特徴

直感的な話者（ラベル）切り替え

スマホ・タブレット: 段落を左右にスワイプして話者を切り替え

PC: 段落選択中や空行では ← / → キー、文字入力中は Shift + ← / → で瞬時に切り替え

画面上部の話者チップのタップ・クリックでも即座に割り当て可能

執筆を止めない段落操作

Enter で段落内改行、Shift + Enter で次の段落を自動追加（次の話者へ自動ローテーション）

リアルタイムで合計文字数・セリフ段落数・目安尺（約300文字/分換算）を自動計算

構造・一括編集モード

複数段落を選択しての話者一括変更、複製、ドラッグ＆ドロップでの並び替えに対応

汎用テキスト形式での一括コピペ編集も可能

汎用テキスト（.txt）との高い互換性

話者名「セリフ」 / （ト書き） / ■ シーン の形式で書き出し・読み込み・ドラッグ＆ドロップに対応

PC（Chrome / Edge）ではローカルファイルへの直接上書き保存（Ctrl + S）にも対応

ダークモード搭載



⚠️ ご利用上の注意（データ保存について）

編集中のデータはブラウザ内（localStorage）に自動保存されます。

ブラウザの履歴・キャッシュ（サイトデータ）の削除やシークレットモードでの利用ではデータが消去されるため、大切な原稿はこまめに「保存(.txt)」から端末に保存することをおすすめします。
